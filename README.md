# 住宅ローン返済比率計算

借入金額・借入期間・審査金利・年収から、年収に対する住宅ローンの返済比率を計算するWebページです。

公開URL: https://suu-f.github.io/loan-ratio/

- 元利均等返済で月々の返済額を計算(1円未満切り捨て)
- 返済比率 = 月々の返済額 × 12ヶ月 ÷ 年収
- 年収別の基準で判定: 500万円以上40% / 450万円以上35% / 400万円以上30% / それ未満25%

例) 借入金額3,000万円・借入期間40年・審査金利1.35%・年収500万円
→ 80,920円 × 12ヶ月 = 971,040円 ÷ 5,000,000円 = **19.42%**
